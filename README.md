# The Aurelian – Final Website Project  
GIT 215 – Module 7

This project is a two-page website built using HTML and CSS. It includes a homepage and a contact page, both styled to match the Module 7 design requirements. The project demonstrates:

- Linking an external stylesheet  
- Styling a webpage with fonts, colors, spacing, and layout  
- Using CSS Grid and Flexbox  
- Creating a hero section with a background image  
- Styling and submitting a form  
- Adding a site favicon  
- Organizing files into proper folders  

## Project Files
- `index.html`  
- `contact.html`  
- `styles.css`  
- `images/` folder (all images used in the project)  
- `favicon_io/` folder (generated favicon files)  
- `README.md`  
- `LICENSE`
